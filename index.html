ABOUT & PROJECT SCOPE

Readiness-first training for court and field athletes

Built using free tools—Gemini, Canva, and GitHub Pages—to combine 10.A application development and 10.B portfolio presentation in one place.

Problem & Solution

Static workout lists ignore daily fatigue, court or field demands, and tight practice windows. ShuttlePulse AI checks a player's sport focus, skill level, available minutes, and fatigue score (1–10) before recommending warm-ups, drills, and recovery.

It also includes an interactive visual reflex timer in milliseconds (ms) so athletes can check reaction speed and catch false starts.
